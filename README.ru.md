# Пульт — голосовой пульт для Android TV

[English](README.md) | **Русский**

Старый Android-планшет у телевизора становится пультом, которым управляют
голосом. Говоришь с дивана «Пульт, пауза», и видео останавливается. Речь
распознаётся прямо на планшете, без интернета (Vosk, русский язык), а
приставкой он управляет по Wi-Fi тем же протоколом, что и приложение Google TV
на телефоне. Ни облака, ни Google Ассистента, ни root.

```
«Пульт, пауза»                        ⏸  Пауза
«Пульт, перемотай назад на минуту»    ⏪  −1 мин
«Пульт, вниз… вправо… окей»           ⬇  ➡  ⏺  OK
«Пульт, выключи через час»            ⏻  Выключу в 23:40
```

## Возможности

- **Слышит сквозь фильм.** Проверено с дивана примерно в 3 метрах: при
  YouTube на обычной громкости распознаны 16 команд из 16, ложных срабатываний
  от телевизора не было. Хватило встроенных микрофонов планшета.
- **Офлайн и приватно.** Распознавание идёт на планшете по фиксированной
  грамматике примерно из 350 русских фраз. Звук никуда не уходит.
- **Воспроизведение.** Пауза и продолжение, громкость, звук вкл/выкл,
  перемотка на любое время, «начни с начала», «пропусти заставку», следующая и
  предыдущая серия, «что играет» и «сколько осталось».
- **Навигация.** «Окей», «назад», стрелки, «домой». После любой из них ещё 6
  секунд можно говорить следующие без «Пульт»: «Пульт, вниз… вниз… окей».
- **Питание.** Выключает и включает телевизор: приставка включает его по
  HDMI-CEC. Таймер сна: «через час» или «после этой серии».
- **Приложения и поиск.** Открывает YouTube, Кинопоиск, Okko, Plex и VK Видео,
  ищет в YouTube голосом.
- **Два шага.** Скажи «Пульт», сделай паузу, потом команду. Одиночное «Пульт»
  телевизор не трогает: если его включит похожее слово из ТВ («пункт», «путь»),
  на планшете просто мелькнёт «Слушаю…».
- **Тихий отклик.** Короткая надпись поверх того, что на экране планшета
  (например, часов). Никаких звуков.
- **Тихий режим.** После установки приложение только записывает, что сделало
  бы, пока ты не включишь управление.

## Как это устроено

```
микрофон планшета ─▶ Vosk (грамматика команд) ─▶ Android TV Remote v2 (TLS, сопряжение один раз) ─▶ приставка
                                              └─▶ помощник на приставке (по желанию, HTTP в домашней сети) ─▶ медиасессии
```

Два APK:

| APK | Где работает | Что делает |
| --- | --- | --- |
| `tvvoice.apk` («Пульт») | планшет | Постоянно слушает (служба переднего плана), распознаёт «Пульт, …» и шлёт кнопки приставке. |
| `tvhelper.apk` («Пульт · помощник») | приставка, **по желанию** | Видит медиасессии приставки: точная перемотка в любом приложении, которое её поддерживает (YouTube, Plex…), следующая и предыдущая серия, что играет и сколько осталось, запуск приложений, поиск. |

Без помощника базовое тоже работает: пауза и продолжение, громкость,
навигация, питание, перемотка YouTube шагами по 10 секунд (через стрелки),
запуск YouTube и поиск в нём.

## Что нужно

- **Планшет:** Android 10+ (arm64), на зарядке, где-нибудь рядом с ТВ.
- **Приставка:** Android TV или Google TV со службой Android TV Remote, то
  есть любая, которой умеет управлять приложение Google TV на телефоне.
- **Для помощника:** доступ по adb к приставке (параметры разработчика →
  отладка по сети).
- **Для «Пульт, включи телевизор»:** приставка должна оставаться в сети в
  режиме ожидания. На Google TV это *Настройки → Система → Питание и
  энергопотребление → Энергорежимы*, режим, в описании которого есть Google
  Cast (средний или выше). В самом экономном режиме приставка во сне выключает
  Wi-Fi, и разбудить её можно только родным пультом.

## Установка

### Планшет

1. Скачай `tvvoice.apk` из
   [Releases](https://github.com/megarohas/megarohas_tv_voice/releases) и
   установи.
2. Открой **Пульт** и разреши микрофон и уведомления.
3. Нажми **Скачать модель распознавания (45 МБ)**, потом **Разрешить надписи
   поверх часов** и **Не ограничивать в фоне**. Каждая кнопка исчезает, когда
   её дело сделано.
4. Нажми **Сопрячь с ТВ**. На телевизоре появится код: введи его и нажми
   **Готово**.
5. Приложение стартует в тихом режиме. Когда будешь готов, нажми **Включить
   управление ТВ**.

Теперь скажи «Пульт, пауза». После перезагрузки и обновлений приложение
запускается само. На Samsung ещё исключи его из *Батарея → Ограничения
использования в фоне*.

### Помощник на приставке (по желанию)

С компьютера в той же сети:

```bash
adb connect <ip-тв>:5555
adb -s <ip-тв>:5555 install tvhelper.apk
adb -s <ip-тв>:5555 shell cmd notification allow_listener com.megarohas.tvhelper/.MediaWatcher
adb -s <ip-тв>:5555 shell appops set com.megarohas.tvhelper SYSTEM_ALERT_WINDOW allow
adb -s <ip-тв>:5555 shell dumpsys deviceidle whitelist +com.megarohas.tvhelper
```

Доступ к уведомлениям нужен только как ключ к медиасессиям других приложений;
уведомлений помощник не читает. Разрешение «поверх окон» позволяет ему
открывать приложения из фона.

Потом дай помощнику и планшету один общий секрет. На планшете включи
*Параметры разработчика → Беспроводная отладка* и сопряги его через `adb pair`:

```bash
TOKEN=$(openssl rand -hex 16)
adb -s <ip-тв>:5555 shell am broadcast -n com.megarohas.tvhelper/.Setup --es token $TOKEN
adb -s <ip-планшета>:<порт> shell am broadcast -n com.megarohas.tvvoice/.AdbControl --es helper_token $TOKEN
```

Если всё получилось, в статусе приложения будет «Помощник на ТВ: на связи».

## Команды

Каждая команда начинается с «Пульт, …». После одного «Пульт» приложение
слушает 4 секунды, и хватит самой команды.

| Что | Как сказать |
| --- | --- |
| Воспроизведение | пауза · стоп · играй · продолжи |
| Громкость | громче · тише · чуть громче · чуть тише · нормальная громкость · выключи звук · включи звук |
| Перемотка | перемотай вперёд / назад (10 с) · перемотай назад на сорок секунд · перемотай на пять минут вперёд · на минуту назад · начни с начала · пропусти заставку |
| Серии | следующая серия · предыдущая серия |
| Что играет | что играет · сколько осталось |
| Навигация | окей · назад · влево · вправо · вверх · вниз · домой (выйти в меню приставки, на главный экран) |
| Питание | включи / выключи телевизор (или приставку) · выключи через полчаса / через час… · выключи после этой серии · отмени таймер |
| Приложения | включи ютуб · кинопоиск · окко · плекс · вк видео |
| Поиск | найди на ютубе … (или пауза после «найди на ютубе», потом запрос) |
| Музыка | включи музыку (будит приставку и запускает станцию в приложении Apple Music из megarohas_amtv) · в нём: дальше / следующий трек · назад / предыдущий трек · пауза · играй · добавь в избранное / мне нравится · мне не нравится |

На сколько можно перематывать: от 5 до 50 секунд, полминуты, от 1 до 10
минут, затем 12, 15, 20, 25, 30, 40, 45 и 50 минут, полчаса, час, полтора часа
и два часа. В каждой перемотке назван её путь. Одно «назад» — это кнопка
«Назад», а одно «вперёд» нарочно ничего не делает. В приложении Apple Music
«назад» — предыдущий трек.

## Настройка с компьютера

Всё, что есть на экране планшета, можно сделать и по adb:

```bash
adb -s <ip-планшета>:<порт> shell am broadcast -n com.megarohas.tvvoice/.AdbControl --es <ключ> <значение>
```

| Ключ | Что делает |
| --- | --- |
| `dry true\|false` | Тихий режим: включить или выключить. |
| `pair 1`, потом `code XXXXXX` | Сопряжение с ТВ. |
| `host <ip>` | Адрес приставки. Пусто — найти её по mDNS (так по умолчанию). |
| `base <n>` | Громкость приставки, к которой возвращает «нормальная громкость» (по умолчанию 10). |
| `helper_token <секрет>` | Общий секрет с помощником. |
| `card true\|false` | Полоска «что играет» поверх часов (по умолчанию выключена). |
| `clips true\|false` | Сохранять 4 с звука вокруг каждого срабатывания, чтобы разбирать ложные (по умолчанию выключено). |
| `music <id станции>` | Станция Apple Music для «включи музыку» (пусто — просто открыть приложение). |
| `say <фраза>` | Сделать вид, что прозвучало «Пульт, <фраза>». |
| `key <код>` | Отправить приставке одну кнопку. |
| `link <url>` | Открыть ссылку на приставке (например, YouTube). |
| `model download` | Скачать модель заново. |

Каждый вызов отвечает статусом. Приёмник защищён разрешением
`android.permission.DUMP`. Оно есть у adb, а обычным приложениям его не
получить, так что ничто другое на планшете не сможет управлять ТВ или включить
запись.

## Заметки

- **Громкость.** Многие телевизоры, в том числе Philips, не принимают
  громкость от источника по HDMI-CEC. Поэтому «громче/тише» меняет громкость
  самой приставки. Держи приставку ниже максимума (например, на 10 из 15), а ТВ
  погромче, чтобы был запас вверх.
- **Кнопки питания.** Служба пульта Google игнорирует кнопки SLEEP и WAKEUP.
  Питание идёт через POWER, а она переключает туда-обратно, поэтому приложение
  сначала смотрит, горит ли экран.
- **Микрофон в фоне.** Android отдаёт фоновому приложению тишину вместо
  ошибки. Приложение замечает тишину и на долю секунды выходит на передний план
  через невидимый экран. Для этого и нужно разрешение «поверх окон».
- **Зелёная точка.** Индикатор микрофона горит всегда: микрофон занят
  постоянно.
- **adb на Android TV** забывает разрешённые компьютеры через 7 дней без
  подключения (*Параметры разработчика → Отключить тайм-аут авторизации ADB*).
  Это важно только для установки помощника, сам пульт adb не использует.
- **Свои фразы.** Кодовое слово и команды русские. Чтобы поменять их, правь
  `Commands.java` и запускай `tools/vocab-check.py`: каждое слово должно быть в
  словаре модели, иначе фраза не сработает никогда.

## Приватность

- Речь распознаётся на планшете, ничего никуда не отправляется. По сети
  приложение ходит только к приставке в домашней сети и один раз за моделью на
  alphacephei.com.
- `events.tsv` в папке приложения записывает распознанные команды текстом.
  Фрагменты звука выключены, пока ты сам их не включишь.
- Помощник отвечает только на запросы с общим секретом (HTTP, порт 8765,
  домашняя сеть).

## Сборка из исходников

Android SDK с build-tools 36 и platform 36, JDK 17, без Gradle:

```bash
make deps                                  # Vosk + JNA с Maven Central (с проверкой SHA-1) и русская модель
make                                       # APK планшета → build/tvvoice.apk
make box                                   # APK помощника → build-box/tvhelper.apk
export ADB_SERIAL=<ip-планшета>:<порт>
make install grant model start             # установка, разрешения, модель, запуск
make box-install link TV=<ip-тв>:5555      # помощник на приставку + общий секрет обоим
make events                                # что оно слышало
```

### Инструменты

- `tools/mictest.sh` — акустический тест. Фразы крупно появляются на
  планшете, пока он записывает комнату, а ТВ синхронно ставится на паузу и
  запускается.
- `tools/eval.py` — оценивает такую запись по грамматике с Vosk на компьютере.
  С `--grammar` и `grammar.json` из приложения проверяет ровно его грамматику.
- `tools/boxkeys.py` — показывает, как приложение на приставке реагирует на
  кнопки пульта (через `dumpsys media_session`).
- `tools/vocab-check.py` — проверяет все слова фраз по словарю модели.
